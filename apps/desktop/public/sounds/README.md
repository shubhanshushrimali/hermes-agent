# Sounds Directory

This directory contains audio files for the Hermes Agent — Aizen Version.

## Required Files

- `aizen-yokoso.mp3` — Startup voice line: "Yōkoso, watashi no Soul Society"
  - Source: Download from Quick Sounds or Voicemod Tuna (free community clips)
  - Target volume: normalize to -14 LUFS
  - Duration: ~2 seconds

## How to add

1. Download the clip from one of these sources:
   - https://quicksounds.com (search "Aizen yokoso")
   - https://tuna.voicemod.net (search "yokoso watashi no soul society")
   - https://soundboards.gg (search "Aizen Yokoso Full")

2. Save as `aizen-yokoso.mp3` in this directory

3. The splash screen will automatically pick it up on next launch
